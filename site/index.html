A data grid that keeps up with your data

<canvas-grid> draws on a canvas, virtualises rows and columns and flashes cells as their values change. It is a plain web component, so it works with any framework, or none. 

npm install @koeroesi86/canvas-grid

Live demo

A web worker simulates a market feed and posts the initial rows and then batches of ticks. The page hands them straight to the grid, which is loaded from unpkg.

Features

  • Built for update streams

    Row updates are merged by id, batched and throttled. Changed cells flash, with the timing and colour configurable.

  • Draws only what you see

    Rows live in a dense array with a binary search for the first visible row, so a frame costs the same with 1,000 rows or a million.

  • Idle means idle

    The render loop is driven by requests. With nothing changing, scrolling or animating, the grid does no drawing at all.

  • Columnar store, lazy formatting

    Values are stored per column and formatted only for cells being drawn, and again only when their value changes.

  • Multi-key sorting

    setSortModel sorts numbers numerically and text with Intl.Collator, keeps ties stable and keeps the order as rows update.

  • Sharp on HiDPI

    Layers and glyphs are rendered at the device pixel ratio, and follow when you zoom or move the window to another screen.

  • Layers and custom renderers

    Stack canvases and register renderers by name. The demo's change column adds a small bar on its own layer.

  • Just a web component

    No framework required, types included, plus an AG Grid-style adapter to ease a migration.

  • Performance is checked in CI

    Every pull request runs a scroll benchmark against its base commit and fails on a draw-time regression or repeated frame stalls.

Get started

From npm

npm install @koeroesi86/canvas-grid
import '@koeroesi86/canvas-grid';

const grid = document.querySelector('canvas-grid');

grid.setColumns([
  'name',
  { id: 'price', displayName: 'Price', width: 80,
    valueFormatter: value => Number(value).toFixed(2) },
]);
grid.setValues([
  { id: 1, name: 'Apple', price: 1.2 },
  { id: 2, name: 'Pear', price: 0.9 },
]);

// later: only the given columns change
grid.queueUpdate({ id: 2, price: 1.0 });

From a script tag

<canvas-grid style="display:block;height:400px"></canvas-grid>
<script src="https://unpkg.com/@koeroesi086/canvas-grid/build/web-component.js"></script>

Feeding it from a worker

const worker = new Worker('data-worker.js');
worker.onmessage = ({ data }) => {
  if (data.type === 'init') {
    grid.setColumns(data.columns);
    grid.setValues(data.rows);
  }
  if (data.type === 'ticks') {
    grid.transaction({ update: data.rows });
  }
};
