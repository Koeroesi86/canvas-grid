# TypeScript

Types ship with the package. Besides the element class (default export) it exports `ColumnHeader`, `ColumnDefinition`, `ColumnState`, `ColumnResizeDetail`, `ColumnResizeSource`, `RowResizeDetail`, `RowResizeSource`, `Transaction`, `CellRenderer`, `CellContext`, `CellState`, `RendererRef`, `LayerOptions`, `SortKey`, `SortDirection`, `SelectionMode`, `SelectionLevel`, `CellRange`, `CellPosition`, `GridSelection`, `SelectionChangeDetail`, `SelectionCopyDetail`, `CellFocusDetail`, `ContextMenuItem`, `ContextMenuDetail`, the editing types (`CellEditable`, `CellEditor`, `BuiltInCellEditor`, `CustomCellEditor`, `CellEditorContext`, `CellEditorInstance`, `SelectOption`, `EditOutOfView`, `CellEditContext`, `CellValueChange`, `CellEditStartDetail`, `CellEditEndDetail` and `CellValueChangedDetail`), and registers `canvas-grid` in `HTMLElementTagNameMap` and `HTMLElementEventMap` (the `columnresizing`, `columnresized`, `rowresizing`, `rowresized`, `selectionchange`, `cellfocus`, `selectioncopy`, `gridcontextmenu`, `celleditstart`, `celleditend` and `cellvaluechanged` events), so `document.querySelector('canvas-grid')` is typed.

> The declarations are single-format. Bundler-style resolution (`moduleResolution: "bundler"`) works; strict Node16 ESM resolution may report the types as CommonJS.
